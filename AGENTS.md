# Project Instructions

## Code Style

- Use TypeScript for all new files
- Prefer functional components in React
- Use snake case for components file names, camelCase for hooks file names
- Don't write comments
- Use context7 if you need any docs

## Architecture

- Use Tanstack Query in data fetching layer, Tanstack forms and zod for form handling
- Break down components larget than 250 lines into smaller components
- Don't write logic in tsx, always seperate logic in custom hooks
- Use Framer Motion to smooth things up
